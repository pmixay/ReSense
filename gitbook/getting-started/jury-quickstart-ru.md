# Кратко для жюри

ReSense 10 раз в секунду отвечает беспилотному поезду метро: есть ли на пути то, чего там быть не
должно, и как далеко. По облаку LiDAR он строит модель нормального тоннеля (полотно, головки
рельсов, ось пути и её кривизну по стенам), вырезает коридор габарита поезда 2,1 × 3,0 м, заданного
организаторами, и сообщает о каждом устойчивом объекте в нём: расстояние вдоль пути, боковое
смещение, размер, уверенность.

## Запуск

**На стенде нет интернета**, поэтому `docker build` там не сработает. Образ сдаётся готовым архивом
`resense-image-<версия>.tar.gz` (рядом его `.sha256`) и загружается без сети; нода сети не требует.

```bash
sudo sysctl -w net.core.rmem_max=33554432                # 0. на хосте, до перезагрузки: буфер UDP для 360° облаков
docker load -i resense-image-<версия>.tar.gz             # 1. один раз, без интернета
docker run --rm -it --net=host --ipc=host resense      # 2. консоль 1: нода (команда образа по умолчанию — для записанных бэгов)
ros2 bag play <бэг> --delay 3 --read-ahead-queue-size 10 # 3. консоль 2: любой пользователь, ROS 2 Humble
ros2 topic echo /resense/decision --field data           # 4. консоль 3: GO | CAUTION | STOP | FAULT
ros2 topic echo /resense/nearest_distance --field data   # 5. расстояние до препятствия, м; −1 — нет
```

**Или одной командой** (нужен только Docker, ROS на хосте не нужен):

```bash
scripts/play_bag.sh <бэг> [--archive resense-image-<версия>.tar.gz]
```

Скрипт проверит и загрузит архив, поднимет буфер UDP, запустит ноду, проиграет бэг от имени
текущего пользователя и напечатает каждую смену решения с расстоянием («12.3 s  STOP  55.6 m»),
затем остановит контейнеры.

Нет ROS 2 на хосте — плеер из того же образа (вместо шага 3):

```bash
docker run --rm --net=host -v <папка с бэгами>:/data:ro resense ros2 bag play /data/<бэг> --delay 3 --read-ahead-queue-size 10
```

## Важно

* **`--net=host` обязателен.** Образ передаёт DDS только по UDP; без общей с хостом сети плеер не
  находит ноду, и `/resense/decision` остаётся `FAULT`. `ROS_DOMAIN_ID` плеера и ноды должен
  совпадать (по умолчанию 0).
* **`freshness_mode:=replay`** — для записанных бэгов; команда образа по умолчанию уже передаёт
  его. Если задаёте свою команду (как для RViz ниже), оставьте его: собственный режим ноды `live`
  сравнивает время кадра с часами системы и для записи покажет `FAULT`.
* **`--read-ahead-queue-size 10`** — поддерживаемый режим проигрывания. С очередью Humble по
  умолчанию (1000 сообщений) плеер после предзагрузки присылает начало записи пачкой, и первые
  секунды результата устаревают.
* **Шаг 0** нужен для 360-градусных облаков с плеером на CycloneDDS; штатному Fast DDS он не мешает.
  Нода пишет WARN при старте, если буфер меньше.

## Что оценивать

| `/resense/decision` | значение |
|---|---|
| `STOP` | **тревога**: подтверждённое препятствие в габарите 2,1 × 3,0 м |
| `CAUTION` | подсказка, **не тревога**: объект у габарита снаружи или за дальностью контроля, известная инфраструктура, сниженная исправность; в обычном тоннеле частая |
| `GO` | препятствие не обнаружено; оценка дальности контроля — `/resense/clear_distance` |
| `FAULT` | входа нет (до первого кадра, > 0,5 с без кадров) или ему нельзя доверять |

Тревога — `STOP` в `/resense/decision` (то же — `true` в `/resense/obstacle_detected`);
расстояние до препятствия вдоль пути — `/resense/nearest_distance`, м (−1 — препятствия нет).
`GO` — результат обнаружения, а не разрешение на движение.

## Увидеть облако

RViz (нужен X11) — вместо шага 2:

```bash
xhost +local:docker && docker run --rm -it --net=host --ipc=host -e DISPLAY -e QT_X11_NO_MITSHM=1 -v /tmp/.X11-unix:/tmp/.X11-unix resense ros2 launch resense_ros detector.launch.py rviz:=true freshness_mode:=replay
```

Без X11 — Foxglove с любого ноутбука в той же сети: [Foxglove](../visualisation/foxglove.md).

## Где взять архив образа

* Релиз GitHub: после публикации архив и его `.sha256` лежат в Assets релиза
  (`scripts/verify_release.sh <тег>` скачает и проверит); вышел ли релиз, сказано в README.
* Артефакт CI: Actions → прогон `ci` нужного коммита `main` (задание `offline-build` зелёное) →
  Artifacts → `resense-image-<версия>-<коммит>` (zip с `.tar.gz` и `.sha256`, хранится 30 дней,
  нужен вход в GitHub).
* Без CI: `scripts/export_image.sh` на машине с интернетом → `dist/resense-image-<версия>.tar.gz`
  и `.sha256`.
* С интернетом шаг 1 можно заменить сборкой: `docker build -t resense -f docker/Dockerfile .`
* Проверка: `sha256sum -c resense-image-<версия>.tar.gz.sha256` или `scripts/load_image.sh <архив>`
  (сумма, загрузка и запуск образа без сети).
