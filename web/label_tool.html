    Frames come from the loaded results.jsonl (its required frame key = absolute bag frame index) or are typed by hand. Key in gt.json: index zero-padded to 5 digits, e.g. 00042. A frame marked "checked, clear" is exported with an empty list.

    Label format and review notes
    Same shape as resense inject writes: {"<frame>": [{"kind","size":[L,W,H],"distance","lateral","yaw_deg","reflectivity","label","in_gauge","n_points"}]}. distance = m along the track to the nearest face, lateral = m from the track axis (+ left); in_gauge defaults to horizontal footprint overlap with the strict 1.05 m half-width. Check height and override the checkbox manually when needed: a value set by hand is kept when the object is edited afterwards. Detector-prefilled boxes are suggestions, not independent ground truth: review the original cloud before saving. n_points = 1 means "visible, count unknown" (resense eval skips entries with 0 as occluded).
