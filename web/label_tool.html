    Same shape as resense inject writes: {"<frame>": [{"kind","size":[L,W,H],"distance","lateral","yaw_deg","reflectivity","label","in_gauge","n_points"}]}. distance = m along the track to the nearest face, lateral = m from the track axis (+ left); in_gauge defaults to |lateral| < 1.3 m; n_points = 1 means "visible, count unknown" (resense eval skips entries with 0 as occluded).
