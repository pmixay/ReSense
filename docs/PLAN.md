## Состав и роли

Организаторы рекомендуют пять ролей (README кейса): системный аналитик, инженер компьютерного
зрения, разработчик робототехники (ROS 2), специалист по работе с данными, разработчик ПО
(C++/Python). На четверых они распределены так (капитан — лид, второй участник — фронтенд):

| # | Участник | Роли по README организаторов | Зона ответственности | Ключевые артефакты |
|---|---|---|---|---|
| **P1** | **Капитан (лид)** | **Системный аналитик** + **Разработчик робототехники (ROS 2)** | требования ТЗ → архитектура и интерфейсы; ROS 2-нода, сообщения, launch, Docker; воспроизводимость «docker build → run → bag play»; протокол оценки; связь с организаторами и расширенный датасет; интеграция веток; финальная сборка и загрузка | `docker/`, `ros2_ws/`, `README.md`, `docs/ARCHITECTURE.md`, `docs/CAPTAIN.md` |

производительности, то есть к зоне P3.

## Правила

* Каждый PR — с зелёным CI и ревью; сливает капитан; красный `main` автор чинит за 1 ч или
  откатывает. Чужие файлы — только с согласия владельца (карта владения — [`CAPTAIN.md`](CAPTAIN.md) §8).
* Детектор и его конфиг запечатаны с 27.09 ([`DETECTOR_FREEZE.md`](DETECTOR_FREEZE.md), проверяет
  CI); меняются только нода, образ, инструменты и документы. Изменение детектора — только с полным
  регрессионным шлюзом, ревью безопасности и новой печатью ([`CAPTAIN.md`](CAPTAIN.md) §6).
* Числа живут в одном месте: [`EXPERIMENTS.md`](EXPERIMENTS.md) и сводка README; оценка по
  критериям — только [`SCORECARD.md`](SCORECARD.md).

## Риски

* **Ложные STOP** на платформах и у стрелок (5 эпизодов на 88 с `squareT_platform_squareT_switch` и
  2,3 эпизода на км в 20-минутной поездке по исторической оценке 28.09; node-path 13.10 —
  32 эпизода на 13 км, ≈2,5/км; шлюз кэша — 30 эпизодов / 27 событий) — главный риск для 8.1.
* **Дальность**: перенос реального человека (28.09, **старый детектор**) дал STOP на 60 м
  в 11 окнах из 15, на 100 м — в 6; node-path 13.10: кубы 0,3 м на рельсе / по центру —
  48–56 м, краевой — 35 м; за доверенной
  дальностью оси (короткой у платформ) объект на пути — CAUTION, а не STOP.
* **Контрольные данные незнакомы**: все цифры получены на записях, на которых настраивались правила.
* **Запуск у жюри**: без `--read-ahead-queue-size 10` плеер Humble отправляет запись пачкой, и
  результаты устаревшие; `--net=host` обязателен; архив опубликован, офлайн-пересборка — задача E2.
* **Правила 29.09** проверены ревью безопасности только после включения: запрет эго-движения
  опирается на оценку скорости по LiDAR и не даёт начать STOP дальше 25 м объекту, уходящему вперёд
  быстрее ~0,65 скорости поезда; постоянную `ego_speed_mps` задавать нельзя ([`ALGORITHM.md`](ALGORITHM.md)).
* **Стенд без интернета и без GPU-зависимостей**: образ поставляется архивом, CUDA не нужна
  ([`ARCHITECTURE.md`](ARCHITECTURE.md) «GPU: evaluated, not used»).
