## Правила

* Каждый PR — через ревью участника из другой зоны (в GitHub); `main` всегда собирается в Docker
  и проходит `pytest`; сливает капитан; красный `main` автор чинит за 1 ч или откатывает.
* Чужие файлы — только с согласия владельца.
* Заморозка: детектор и конфиг — **26.09, 20:00**, документация — **27.09, 20:00**, с 28.09 —
  только блокеры. Порог для изменения детектора и правила слияния — [`CAPTAIN.md`](CAPTAIN.md) §6.
* Числа живут в одном месте: [`EXPERIMENTS.md`](EXPERIMENTS.md) и сводка README; остальные
  документы ссылаются на них.

## Риски

* Ложные STOP на станциях и у торца платформы — главный риск для 8.1. 25.09 включено правило
  «длинная конструкция над путём»: на пустых бэгах 27 → 17 эпизодов STOP (10 из 25 на станции
  убраны), поездка 47 → 46 событий; остаются торец платформы на 82,9 м (ошибка оси) и детали
  стрелки на 147,5 м ([`EXPERIMENTS.md`](EXPERIMENTS.md) §1f).
* Дальность подтверждена только на синтетике (человек 148–154 м); на бэге организаторов объекты
  внутри габарита получают первый STOP не дальше 101 м, кубы 0,3 м — с 34–43 м.
* Объект на полотне между рельсами не сообщается (политика ниже габарита); 25.09 организаторы
  подтвердили: это не препятствие (ответ на Q3, [`organizers/answers.md`](organizers/answers.md)
  §8). Ящик 0,5 м на полотне выше пола габарита по-прежнему находится поздно (1 из 6).
* Время на кадр — 42–64 мс в среднем, p95 53–78 мс на 4 ядрах (23.09, путь numpy, без монитора
  состояния); ядра на C++ сокращают время детектора на 38–57 %, их сборку в Docker CI
  подтверждает в каждом прогоне с 24.09; стенд i7-9700E до сдачи команде недоступен (ответ
  организаторов 25.09, [`organizers/answers.md`](organizers/answers.md) §6), замер — на 8-ядерной
  машине команды (комплект готов, запуск — при развёртывании); на 4 vCPU узел на 360° — p95
  112–130 мс при пороге 100 мс.
* На стенде нет интернета (организаторы, 25.09, §7): жюри запускает `docker load` архива образа
  (0,49 ГиБ в CI); форма загрузки принимает ссылки без лимита размера (§8). CI на каждом коммите
  загружает архив и прогоняет через этот образ синтетические бэги без интернета; релизы отложены
  капитаном (25.09), `release.yml` не запускался; прогон без сети на исходных бэгах — при
  развёртывании, позже (действие 15).
* Стенд организаторов без GPU-зависимостей: не тащить CUDA в обязательные зависимости; GPU
  оценён 24.09 и не используется ([`ARCHITECTURE.md`](ARCHITECTURE.md) «GPU: evaluated, not
  used»).
