## Состав и роли

Организаторы рекомендуют пять ролей (README кейса): системный аналитик, инженер компьютерного
зрения, разработчик робототехники (ROS 2), специалист по работе с данными, разработчик ПО
(C++/Python). На четверых они распределены так (капитан — лид, второй участник — фронтенд):

| # | Участник | Роли по README организаторов | Зона ответственности | Ключевые артефакты |
|---|---|---|---|---|
| **P1** | **Капитан (лид)** | **Системный аналитик** + **Разработчик робототехники (ROS 2)** | требования ТЗ → архитектура и интерфейсы; ROS 2-нода, сообщения, launch, Docker; воспроизводимость «docker build → run → bag play»; протокол оценки; связь с организаторами и расширенный датасет; интеграция веток; финальная сборка и загрузка | `docker/`, `ros2_ws/`, `README.md`, `docs/ARCHITECTURE.md`, `docs/CAPTAIN.md` |

производительности, то есть к зоне P3.

## Правила

* Каждый PR — с зелёным CI и ревью; сливает капитан; красный `main` автор чинит за 1 ч или
  откатывает. Чужие файлы — только с согласия владельца (карта владения — [`CAPTAIN.md`](CAPTAIN.md) §8).
* Детектор и его конфиг запечатаны ([`DETECTOR_FREEZE.md`](DETECTOR_FREEZE.md); эталон дерева — печать кандидата 1.3.0, 42 файла, `verify` PASS на 22.10; выпущенный v1.2.0 опечатан отдельно, R3, 40 файлов).
  Изменение детектора — только в отдельной ветке: протокол до замеров, полный регрессионный шлюз без `--allow`,
  независимое ревью и новая печать капитаном ([`CAPTAIN.md`](CAPTAIN.md) §6).
* Числа живут в одном месте: [`EXPERIMENTS.md`](EXPERIMENTS.md) и сводка README; оценка по
  критериям — только [`SCORECARD.md`](SCORECARD.md).

  27 событий) — главный риск для 8.1. В 1.2.0 включены F1a и H′ (BACKLOG F1), итоговые числа — pending.
* **`CAUTION` на объекте в габарите — пропуск** (ответ организаторов 19.10); **движущиеся объекты** не проверены правилами,
  рассчитанными на неподвижный или приближающийся объект (карточка M1).
* **Дальность**: node-path 13.10 (v1.0.0): кубы 0,3 м на рельсе / по центру — 48–56 м, краевой — 35 м; за доверенной дальностью
  оси (короткой у платформ) объект на пути — CAUTION, а не STOP; на кривых K2 выключен в опубликованном v1.2.0 и включён только в кандидате 1.3.0 (первый STOP человека на `roundT_doubleT` 46,49 → 71,19 м; измерено в выборке, ценой +3 ложных эпизодов STOP на поездке и времени кадра; не выпущено).
* **Контрольные данные незнакомы**: все цифры получены на записях, на которых настраивались правила.
* **Запуск у жюри**: без `--read-ahead-queue-size 10` плеер Humble отправляет запись пачкой, и результаты устаревшие;
  `--net=host` обязателен; архивы v1.0.0 и v1.2.0 опубликованы (v1.2.0 — 20.10), офлайн-пересборка — E2 (локально PASS).
