**Кратко.** Семнадцать решений, которые определили ReSense: вопрос, что измерили, результат,
решение и где доказательство. Каждое правило детектора прошло регрессионный шлюз (с 20-минутной
поездкой, кроме решения о задержке); критерии, как правило, записывали до прогона, и одно правило,
`health.clear_cap`, включено, хотя свой предел не выдержало (№ 13). Что не прошло, осталось
выключенным флагом с цифрами. Габарит, работа без карты и без скорости поезда — из ответов
организаторов.

Counts are alarm frames / events / STOP episodes, as in [`CHANGELOG.md`](../CHANGELOG.md). "Five
bags" = the five obstacle-free recordings (2 287 frames, real); "ride" = the 20-minute recording
(11 271 frames, 13 km, real); set O = the organizers' synthetic objects; set F = our synthetic
objects on the moving ride. Every detector rule was gated by `scripts/regression_gate.py`.
