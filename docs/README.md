## Экспериментальная линия (влита в `main` 29.09)

Экспериментальная линия P3 влита в `main` 29.09 (PR #27); её правила выключены по умолчанию
(профили `configs/experimental_*.yaml`). Вечером 29.09 (PR #29) по полному шлюзу включены три правила
против ложных тревог, идеи которых взяты из открытых репозиториев других команд кейса 05
([`ALGORITHM.md`](ALGORITHM.md) §3.5b, [`DECISIONS.md`](DECISIONS.md) строка 30); ночью одно из них,
`shell`, выключено после независимого ревью безопасности (строка 31); остальные кандидаты того дня
выключены. Текущие измерения и ограничения обзоров: [`EXPERIMENTS.md`](EXPERIMENTS.md),
[`SCORECARD.md`](SCORECARD.md).
Приёмка полного тайминга и печать: [`DETECTOR_FREEZE.md`](DETECTOR_FREEZE.md) и

  evidence.

  журналу, [`archive/EXPERIMENTS_log_2026-09.md`](archive/EXPERIMENTS_log_2026-09.md).
