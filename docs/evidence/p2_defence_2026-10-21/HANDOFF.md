## Команды живого показа (из корня репозитория)

ROS 2 на хосте не требуется. X11 и разрешение доступа Docker к дисплею нужны для RViz.
Один бэг за запуск соответствует проверенным записям:

```bash
IMAGE=resense:p2-1.2.0-31154690 LIBGL_ALWAYS_SOFTWARE=1 \
  scripts/run_demo.sh --rate 0.5 --sensor-profile pandar128 \
  --clear-range-policy conservative data/p2-defence/for_hackathon/doubleT_obstacle

IMAGE=resense:p2-1.2.0-31154690 LIBGL_ALWAYS_SOFTWARE=1 \
  scripts/run_demo.sh --rate 1 --sensor-profile falcon_ros \
  --clear-range-policy conservative data/p2-defence/falcon_person_verified
```

Скрипт умеет последовательные бэги в одном узле; **этот пакет видео проверяет отдельные
запуски**. Переход Pandar → Falcon, паузу и скорость на машине капитана проверить
отдельно. В RViz для Falcon включить сырой топик `/iv_points` (в стандартной раскладке
его нет), установить взгляд вдоль +X. Проверенные display-only раскладки:
[`replay/falcon/capture.rviz`](replay/falcon/capture.rviz),
[`replay/pandar/capture.rviz`](replay/pandar/capture.rviz).
Параметры детектора в них не меняются. Для точного воспроизведения видеозаписи:

```bash
docker build -f docs/evidence/p2_defence_2026-10-21/Dockerfile.capture \
  -t resense:p2-capture-31154690 .
docker run --rm -e ROS_DOMAIN_ID=173 \
  -v "$PWD/data/p2-defence/falcon_person_verified:/bag:ro" \
  -v "$PWD/out/p2-defence:/out" \
  -v "$PWD/docs/evidence/p2_defence_2026-10-21:/tools:ro" \
  resense:p2-capture-31154690 python3 /tools/capture_chain.py \
  --bag /bag --profile falcon_ros --rate 1 --out /out/falcon-repeat
```

## Что действительно измерено

| прогон | скорость | первый STOP после команды¹ | дистанция | вход / статусы кадров |
|---|---:|---:|---:|---:|
| Pandar | 0,5× | 5,04 с | 55,53 м | 201 / 201 |
| Falcon, холодный старт окна, `falcon_ros` | 1× | 3,79 с | 144,00 м | 499 / 499 |

¹ Включая `--delay 3`; после первого принятого облака — 1,17 / 0,22 с.
Все CDR принятых облаков побайтно совпадают с бэгами; временные метки **каждого**
статуса сопоставлены с исходными сообщениями. Falcon: первый STOP соответствует
ранее проверенной траектории человека (кадр 2805, опоры 2800/2825), а не конструкции
на 115 м. Это проверка демонстрации, не новая оценка качества всего окна.

Не говорить «STOP непрерывен во всём Falcon-окне»: имеются CAUTION/GO. 144 м —
результат именно холодного старта окна с явными осями; ~125 м в слайдах относится
к полному прогону с автоматическим поиском ориентации. У Pandar в начале были два
`source_stale`, в потоке есть watchdog-сообщения; у обоих первый кадр подтверждает
эпоху. Нулевой индекс `node.frames` публикуется до инкремента: 200/498 означают
201/499 статусов, не потерю последнего кадра. Pandar `dropped_frames=4` сохранён
как телеметрия, несмотря на полное совпадение входа и статусов. Это не бенчмарк S5.
