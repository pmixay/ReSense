## Проверки и воспроизведение

- [HANDOFF.md](HANDOFF.md) — бэги, образ, команды, перенос, ограничения и приёмка
  на втором устройстве. Большие данные/архив образа хранятся в `data/p2-defence/`
  вне git; MP4, PPTX, PDF и доказательства входят в коммит.
- [falcon_bag.json](falcon_bag.json) — полный archive/raw digest, 499 хэшей CDR,
  индексы исходных кадров, точные временные метки. Весь архив прочитан; весь сырой
  SQLite 20,28 GB хэширован, сохранено только окно 2,1 GiB.
- [replay/](replay/) — сжатые необрезанные статусы, логи узла/плеера/RViz,
  `ros2 bag info`, времена запуска и display-only раскладки. Все 700 входных
  CDR и 700 статусов кадров совпали с бэгами. Статусы до входа/после конца
  сохранены отдельно от покадрового счёта.
- [archive_receipt.json](archive_receipt.json) — хэш архива локального образа,
  OCI manifest, config и все слои проверены; это не проверка загрузки на втором ПК.
- [SHA256SUMS](SHA256SUMS) — проверять из корня репозитория:
  `sha256sum -c docs/evidence/p2_defence_2026-10-21/SHA256SUMS`.

Инструменты этого каталога не меняют детектор. `prepare_falcon.py` восстанавливает
окно из архива; `capture_chain.py` записывает настоящий дисплей и DDS в контейнере;
`verify_image.py`, `verify_playback.py`, `verify_deck.py` проверяют артефакты.
`build_review_deck.py` создаёт отдельную колоду на основе существующих макетов.
Python-зависимости подготовки: PyYAML, zstandard, python-pptx, Pillow, PyMuPDF;
для PDF — LibreOffice и Montserrat (локальные WOFF2 преобразованы fontTools/brotli).
Окружение подготовки — `out/p2-defence/venv`, сырые записи экрана —
`out/p2-defence/{pandar,falcon}-final/`. Сборка PDF выполнена через `p2-office:local`.

### Наблюдения, которые нельзя скрывать в питче

- Falcon: 144 м — **холодный старт окна с `falcon_ros`**, не замена ~125 м
  полного прогона. Внутри окна есть CAUTION/GO; первый STOP сопоставлен с
  независимыми опорами человека, но покадровое качество окна заново не оценивалось.
- Pandar: первые кадры включают `epoch_unconfirmed`, catchup и два `source_stale`;
  watchdog тоже опубликован. Все исходные сообщения и статусы кадров присутствуют.
  Телеметрия `dropped_frames=4` сохранена. Это не замер 10 Гц или S5.
- На видео нет записи команды `docker load`; оно показывает уже запущенную
  цепочку узел → bag → RViz → STOP. Два запуска склеены между бэгами;
  смена бэгов в одном узле на машине капитана ещё требует репетиции.
- Первые пробные запуски не приняты: `/tmp` исчерпал квоту; вывод подготовки
  перенесён в `out/`. Пробная запись Falcon не имела сырого `/iv_points` в RViz;
  добавлен топик и сделана новая запись. Финальная версия завершает ffmpeg
  командой `q`; первый дубль завершался SIGINT и не прошёл проверку exit code.
- Первичная проверка всей `web/demo` в минимальном окружении не прошла из-за
  отсутствия scipy; окружение подготовки дополнено и проверка повторена.
