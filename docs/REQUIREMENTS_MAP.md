## 1. Среда и запуск (ТЗ §3)

| требование | где выполнено | чем подтверждено |
|---|---|---|
| Ubuntu 22.04, ROS 2 Humble, Docker | образ на `ros:humble-ros-base-jammy` ([`docker/Dockerfile`](../docker/Dockerfile)) | CI, задание `docker`: сборка образа с нуля на каждом пуше |
| 1. запуститься в Docker-контейнере | `docker run --rm -it --net=host --ipc=host resense` (команда образа запускает ноду) | CI `docker`, `offline-build` |
| 2. подключиться к ROS 2 | нода `resense_detector` ([`detector_node.py`](../ros2_ws/src/resense_ros/resense_ros/detector_node.py)), Fast DDS по UDP | CI: плеер и слушатель со штатным Fast DDS от uid 1000 из другого контейнера |
| 3. прочитать bag-файл | `ros2 bag play <бэг>` из любой консоли (ответ организаторов 23.09: бэг проигрывается из консоли); нода подписана на обе пары топик / frame id и находит другие `PointCloud2` | CI проигрывает оба исходных бэга организаторов и синтетические бэги с обеими парами |
| 4. обработать поток | 10 кадров/с, каждое облако → решение | [`EXPERIMENTS.md`](EXPERIMENTS.md) «Скорость и ресурсы» |
| 5. вывести результат | `/resense/decision` (`GO`/`CAUTION`/`STOP`/`FAULT`), `/resense/nearest_distance`, ещё 10 топиков и JSON статуса | README «Кратко для жюри», GitBook «Топики и JSON статуса» |
| дополнительные пакеты ставятся при сборке образа | всё в `docker/Dockerfile`; на стенде нет интернета, поэтому образ поставляется архивом `docker load` | CI `offline-build`: архив → `docker rmi` → `docker load` → бэги через ноду без сети |
| GPU — только если нужен | не нужен: только CPU | [`ARCHITECTURE.md`](ARCHITECTURE.md) «GPU: evaluated, not used» |

## 2. Демонстрация (ТЗ §4)

| шаг ТЗ | чем показываем |
|---|---|
| 1. запустить контейнер | `docker load -i resense-image-v1.0.0.tar.gz` → `docker run … resense` |
| 2. начать проигрывание бэга | `ros2 bag play <бэг> --delay 3 --read-ahead-queue-size 10` |
| 3. показать поступающие лидарные данные | RViz (`rviz:=true`, раскладка [`resense.rviz`](../ros2_ws/src/resense_ros/rviz/resense.rviz)), Foxglove ([`web/foxglove_layout.json`](../web/foxglove_layout.json)), веб-дашборд ([`web/index.html`](../web/index.html)) |
| 4. обнаружение препятствия | `doubleT_obstacle`: человек в габарите с 8-го кадра — `STOP` |
| 5. результат | `/resense/decision` = `STOP`, `/resense/nearest_distance` ≈ 55,5–56,6 м; одной командой — `scripts/play_bag.sh <бэг>` |
| цепочка «тоннель → облако → алгоритм → препятствие → расстояние» | видео [`docs/video/docker_chain_rviz.mp4`](video/docker_chain_rviz.mp4) и обзор [`resense_overview.mp4`](video/resense_overview.mp4); сценарий живой демонстрации — [`web/DEMO_HANDOFF.md`](../web/DEMO_HANDOFF.md), [`PRESENTATION.md`](PRESENTATION.md) |
| демонстрация в реальном времени через удалённый рабочий стол | трансляция RViz / Foxglove (порт 8765) — [`web/README.md`](../web/README.md) |
